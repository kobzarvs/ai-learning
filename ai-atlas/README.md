# AI Atlas

Одностраничный атлас машинного обучения на русском языке. Визуальный ориентир — присланные примеры Heptabase: тематические области, конспекты-карточки, связи и свободный холст.

## Запуск

```sh
cd /Users/diver/prj/ai/learning/ai-atlas
npm run dev
```

Открыть http://127.0.0.1:4173. Установка зависимостей не требуется. Node.js 20+.

Для просмотра без сервера открыть файл `ai-atlas.html` в корневой папке проекта обучения. Это автономная сборка с теми же данными и функциями. Выбор маршрута хранится в браузере; поведение localStorage для локальных файлов зависит от браузера. Маршрут можно скачать в Markdown.

## Управление

- По умолчанию включён PAN: перетаскивание и прокрутка перемещают холст. Для открытия карточек мышью включи инструмент выбора (стрелка). В режиме выбора можно тянуть фон; зажать Shift, чтобы временно включить Pan и тянуть поверх карточек. Отпускание Shift не прерывает начатое перетаскивание: жест заканчивается при отпускании мыши, затем возвращается выбранный инструмент. Кнопка Pan включает постоянный режим.
- Масштаб: pinch (сведение или разведение двух пальцев) на трекпаде и сенсорном экране, Ctrl + колесо или кнопки +/−.
- Обычная прокрутка двумя пальцами или колесом перемещает холст по обеим осям в любом режиме; Shift для этого не нужен.
- Меню слева вверху: области и подразделы.
- Клик по карточке или названию раздела: отдельный холст темы. «Назад» возвращает на предыдущий холст с прежним положением камеры.
- Внутри темы: статьи, Python-пример, Rust-пример (где добавлен), эксперимент и личные заметки. Статьи открываются в большом окне чтения.
- Нажатие на фон за окном закрывает статью, маршрут или выбор темы. Редактор заметки и группы закрывается только явной кнопкой: случайный клик снаружи или Escape не сбрасывает ввод.
- Разделы статьи обозначены смысловыми пиктограммами; условие задачи выделено голубым фоном и тонкой рамкой. Текст интерфейса — от 20 px; масштаб холста регулируется отдельно.
- Тематические миниатюры помогают различать текст, изображения, звук, графы, деревья и другие направления. При увеличении карточек сохранённая структура холстов переносится автоматически.
- Карточки перемещаются за ⠿; Ctrl/⌘ + клик выбирает несколько. «Выделить» включает рамку, «Группа» объединяет выбранное или создаёт пустую именованную группу.
- Заголовок группы можно перетащить вместе со всеми карточками. Новая заметка помещается в выбранную группу; карточки можно переносить в рамку или из неё.
- «＋ Тема» добавляет ссылку на любое другое подпространство. «＋ Заметка» создаёт свою статью с названием и текстом.
- Раскладка, группы и заметки сохраняются в этом браузере. «Скачать копию» экспортирует все холсты в JSON; импорт объединяет данные, сохраняя различающиеся карточки. ↶ отменяет последние изменения в текущем сеансе.
- Подчёркнутые сокращения и термины: пояснение при наведении, нажатии или фокусе клавиатуры в подробном описании.
- Звёздочка: добавить в маршрут. Маршрут сохраняется локально и экспортируется в Markdown.
- `/`: поиск; `F`: обзор всей карты; стрелки при фокусе на холсте: перемещение.
- Прямые ссылки: `#cnn`, `#quantum`, `#projects`, `#root` и другие ID из данных.

Цвета обозначают области, линии — выбранные содержательные связи. Линии прокладываются по свободным промежуткам, огибают карточки и посторонние группы; выбранная карточка подсвечивает свои связи. Это не обязательная последовательность обучения. Своими заметками и группами можно управлять внутри тематических холстов. Синхронизации между устройствами и совместного редактирования нет; для переноса используй JSON-копию.

## Содержание

113 тем, 5 областей: задачи и данные; семейства моделей; способы обучения; компактные модели и системы; фундамент, качество и проекты. У архитектуры, обучающего сигнала и оптимизации разные роли: они могут сочетаться. Карта не претендует на перечисление всех научных публикаций.

Для всех 113 тем добавлен запускаемый Python-пример; в 25 темах есть Rust + Burn. Python 3.14 используется в инструкциях и автопроверке. Код, команды запуска, пояснения, ожидаемый результат, ограничения и задание находятся в окне чтения. Версии PyTorch 2.14.1 и Burn 0.22.1 закреплены по официальным релизам; статус численной проверки описан в `../examples/README.md`.

Основной редактируемый файл — `../map-data.json`. `map-data.js` генерируется из него при сборке. Ссылки на первоисточники включены там, где они подобраны; собственные предложения учебных проектов не выдаются за цитаты.

## Подсветка и графика

Prism 1.30.0 включён локально, без CDN. Поддерживаются Python, Rust, Bash и TOML: ключевые слова, функции, строки, числа, комментарии и остальные конструкции соответствующих грамматик. Копирование и скачивание возвращают исходный код без HTML-разметки. Лицензия MIT находится в `vendor/PRISM-LICENSE.txt`.

`art/topic-icons.png` — созданный для атласа лист из 24 иллюстраций. `art.js` выбирает изображение по смыслу темы. Иконки заголовков статей заданы в `ui.js`. Автономный HTML содержит всю графику и подсветку внутри файла.

## Проверка и сборка

```sh
npm test
npm run build
```

Тесты проверяют последовательности Shift/мыши, сохранение выбранного инструмента, пояснения сокращений, полноту тем, ссылки в данных, отсутствие наложений карточек, поиск, геометрию масштаба и обработку повреждённого сохранения маршрута. Дополнительные проверки подтверждают отсутствие пересечений всех 13 связей с карточками и посторонними группами. Автоматические проверки логики не заменяют визуальную проверку в браузере.

## Vercel и GitHub

Репозиторий: https://github.com/kobzarvs/ai-learning

В корне репозитория есть `vercel.json`: сборка запускает тесты, затем `ai-atlas/build.mjs`; публикуется только `ai-atlas/dist`.

Проект Vercel `ai-atlas` подключён к `kobzarvs/ai-learning`. Обновления `main` запускают автоматическую публикацию: https://ai-atlas-plum.vercel.app/. Корневая конфигурация запускает проверки перед сборкой.

Если проект настроен с Root Directory = `ai-atlas`, используется конфигурация `ai-atlas/vercel.json`; это тоже поддерживается. В настройках проекта не должно быть конфликтующих ручных переопределений build/output.

Для ручной публикации из подпапки:

```sh
cd ai-atlas
npx vercel --prod
```

## Файлы

`index.html` — интерфейс; `styles.css` — оформление; `core.js` — независимая логика карты, поиска и геометрии; `app.js` — взаимодействия карты; `workspace-core.js` и `workspace.js` — тематические холсты, группы, заметки и чтение; `lesson-data.js` — генерируемые уроки; `build.mjs` — сборка; `server.mjs` — локальный просмотр; `test/core.test.cjs` — проверки.

Никакой аналитики, загрузки внешних шрифтов или библиотек из сети. Тексты и ссылки статические. Браузерные данные не отправляются на сервер.
