# AI Atlas

Одностраничный атлас машинного обучения на русском языке. Визуальный ориентир — присланные примеры Heptabase: тематические области, конспекты-карточки, связи и свободный холст.

## Запуск

```sh
cd /Users/diver/prj/ai/learning/ai-atlas
npm run dev
```

Открыть http://127.0.0.1:4173. Установка зависимостей не требуется. Node.js 20+.

Для просмотра без сервера открыть файл `ai-atlas.html` в корневой папке проекта обучения. Это автономная сборка с теми же данными и функциями. Выбор маршрута хранится в браузере; поведение localStorage для локальных файлов зависит от браузера. Маршрут можно скачать в Markdown.

## Управление

- Перемещение: тянуть фон; зажать Shift, чтобы временно включить Pan и тянуть поверх карточек. Отпускание Shift не прерывает начатое перетаскивание: жест заканчивается при отпускании мыши, затем возвращается выбранный инструмент. Кнопка Pan включает постоянный режим.
- Масштаб: колесо, кнопки +/−, жест двумя пальцами на сенсорном экране.
- Shift + прокрутка: перемещение холста по направлению прокрутки без изменения масштаба. Постоянный режим Pan также перемещает холст колесом. Без Shift в режиме выбора вертикальное колесо меняет масштаб.
- Меню слева вверху: области и подразделы.
- Клик по карточке: понятное объяснение, принцип работы, конкретный пример, ограничения и источники.
- Подчёркнутые сокращения и термины: пояснение при наведении, нажатии или фокусе клавиатуры в подробном описании.
- Звёздочка: добавить в маршрут. Маршрут сохраняется локально и экспортируется в Markdown.
- `/`: поиск; `F`: обзор всей карты; стрелки при фокусе на холсте: перемещение.
- Прямые ссылки: `#cnn`, `#quantum`, `#projects`, `#root` и другие ID из данных.

Цвета обозначают области, линии — выбранные содержательные связи. Линии прокладываются по свободным промежуткам, огибают карточки и посторонние группы; выбранная карточка подсвечивает свои связи. Это не обязательная последовательность обучения. Полного редактора заметок или совместного редактирования нет.

## Содержание

113 тем, 5 областей: задачи и данные; семейства моделей; способы обучения; компактные модели и системы; фундамент, качество и проекты. У архитектуры, обучающего сигнала и оптимизации разные роли: они могут сочетаться. Карта не претендует на перечисление всех научных публикаций.

Основной редактируемый файл — `../map-data.json`. `map-data.js` генерируется из него при сборке. Ссылки на первоисточники включены там, где они подобраны; собственные предложения учебных проектов не выдаются за цитаты.

## Проверка и сборка

```sh
npm test
npm run build
```

Тесты проверяют последовательности Shift/мыши, сохранение выбранного инструмента, пояснения сокращений, полноту тем, ссылки в данных, отсутствие наложений карточек, поиск, геометрию масштаба и обработку повреждённого сохранения маршрута. Дополнительные проверки подтверждают отсутствие пересечений всех 13 связей с карточками и посторонними группами. Автоматические проверки логики не заменяют визуальную проверку в браузере.

## Vercel и GitHub

Репозиторий: https://github.com/kobzarvs/ai-learning

В корне репозитория есть `vercel.json`: сборка запускает тесты, затем `ai-atlas/build.mjs`; публикуется только `ai-atlas/dist`.

Проект Vercel `ai-atlas` подключён к `kobzarvs/ai-learning`. Обновления `main` запускают автоматическую публикацию: https://ai-atlas-plum.vercel.app/. Корневая конфигурация запускает проверки перед сборкой.

Если проект настроен с Root Directory = `ai-atlas`, используется конфигурация `ai-atlas/vercel.json`; это тоже поддерживается. В настройках проекта не должно быть конфликтующих ручных переопределений build/output.

Для ручной публикации из подпапки:

```sh
cd ai-atlas
npx vercel --prod
```

## Файлы

`index.html` — интерфейс; `styles.css` — оформление; `core.js` — независимая логика карты, поиска и геометрии; `app.js` — взаимодействия; `build.mjs` — сборка; `server.mjs` — локальный просмотр; `test/core.test.cjs` — проверки.

Никакой аналитики, внешних шрифтов или библиотек. Тексты и ссылки статические. Браузерные данные не отправляются на сервер.
