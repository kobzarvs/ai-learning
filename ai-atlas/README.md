# AI Atlas

Одностраничный атлас машинного обучения на русском языке. Визуальный ориентир — присланные примеры Heptabase: тематические области, конспекты-карточки, связи и свободный холст.

## Запуск

```sh
cd /Users/diver/prj/ai/learning/ai-atlas
npm run dev
```

Открыть http://127.0.0.1:4173. Установка зависимостей не требуется. Node.js 20+.

Для просмотра без сервера открыть файл `ai-atlas.html` в корневой папке проекта обучения. Это автономная сборка с теми же данными и функциями. Выбор маршрута хранится в браузере; поведение localStorage для локальных файлов зависит от браузера. Маршрут можно скачать в Markdown.

## Управление

- По умолчанию включён PAN: перетаскивание и прокрутка перемещают холст. Обычный клик открывает карточку и в PAN; движение больше 5 пикселей начинает перетаскивание холста и отменяет открытие карточки. В режиме выбора можно тянуть фон; зажать Shift, чтобы временно включить Pan и тянуть поверх карточек. Отпускание Shift не прерывает начатое перетаскивание: жест заканчивается при отпускании мыши, затем возвращается выбранный инструмент. Кнопка Pan включает постоянный режим.
- Масштаб: pinch (сведение или разведение двух пальцев) на трекпаде и сенсорном экране, Ctrl + колесо или кнопки +/−.
- Обычная прокрутка двумя пальцами или колесом перемещает холст по обеим осям в любом режиме; Shift для этого не нужен.
- Меню слева вверху: области и подразделы.
- Клик по карточке или названию раздела: отдельный холст темы. «Назад» возвращает на предыдущий холст с прежним положением камеры.
- Внутри темы: статьи, Python-пример, Rust-пример (где добавлен), эксперимент и личные заметки. Статьи открываются в большом окне чтения.
- В примерах выбирается устройство вычислений; отдельного выбора ОС нет. Показанный, скопированный и скачанный код содержит только выбранное устройство. Инструкция указывает имя файла, которое использует команда запуска. Переключение устройства и способа запуска сохраняет прокрутку окна.
- Во вкладках Python, Rust и MLX код использует ширину содержимого окна, а пояснения ограничены удобной для чтения колонкой. Максимальная ширина окна — 1480 px; большие внутренние боковые поля и отступ кода под нумерацией шагов убраны. Размер шрифта остаётся 20 px.
- Статьи и обычные задания открываются в компактном окне до 1160 px. Расширение до 1480 px применяется к коду, интерактивным графикам и карте методов, а не ко всей теме.
- «Классификация и регрессия»: общепринятые названия задач сохранены в заголовке, расшифровка — в описании.
- В «Причинных моделях» один сюжет для статьи, Python и графиков: сотрудники выполняют задания по новой или прежней инструкции. «Эксперимент» содержит управление и два графика в одном горизонтальном ряду; окно занимает доступную ширину. На узком экране ряд прокручивается горизонтально. Положение прокрутки сохраняется при изменении параметров. Графики работают без сети; это учебная симуляция, а не данные предприятия.
- «Методы и случаи» содержит карту семейств причинного вывода с данными, допущениями и примерами, а также опубликованные исследования и отдельно помеченные практические сценарии. Источники доступны у каждого метода и случая.
- Python содержит запуск, код и его разбор. Для остальных тем вкладка «Задание» содержит самостоятельное изменение и шаги проверки гипотезы, без повторения всего Python-разбора. Задание и заметка используют выбранный вариант библиотеки.
- Нажатие на фон за окном закрывает статью, маршрут или выбор темы. Редактор заметки и группы закрывается только явной кнопкой: случайный клик снаружи или Escape не сбрасывает ввод.
- Разделы статьи обозначены смысловыми пиктограммами; условие задачи выделено голубым фоном и тонкой рамкой. Текст интерфейса — от 20 px; масштаб холста регулируется отдельно.
- Тематические миниатюры помогают различать текст, изображения, звук, графы, деревья и другие направления. При увеличении карточек сохранённая структура холстов переносится автоматически.
- Карточки перемещаются за ⠿; Ctrl/⌘ + клик выбирает несколько. «Выделить» включает рамку, «Группа» объединяет выбранное или создаёт пустую именованную группу.
- Заголовок группы можно перетащить вместе со всеми карточками. Новая заметка помещается в выбранную группу; карточки можно переносить в рамку или из неё.
- «＋ Тема» добавляет ссылку на любое другое подпространство. «＋ Заметка» создаёт свою статью с названием и текстом.
- Раскладка, группы и заметки сохраняются в этом браузере. «Скачать копию» экспортирует все холсты в JSON; импорт объединяет данные, сохраняя различающиеся карточки. ↶ отменяет последние изменения в текущем сеансе.
- Подчёркнутые сокращения и термины: пояснение при наведении, нажатии или фокусе клавиатуры в подробном описании.
- Звёздочка: добавить в маршрут. Маршрут сохраняется локально и экспортируется в Markdown.
- `/`: поиск; `F`: обзор всей карты; стрелки при фокусе на холсте: перемещение.
- Прямые ссылки: `#cnn`, `#quantum`, `#projects`, `#root` и другие ID из данных.

Цвета обозначают области, линии — выбранные содержательные связи. Линии прокладываются по свободным промежуткам, огибают карточки и посторонние группы; выбранная карточка подсвечивает свои связи. Это не обязательная последовательность обучения. Своими заметками и группами можно управлять внутри тематических холстов. Синхронизации между устройствами и совместного редактирования нет; для переноса используй JSON-копию.

## Содержание

113 тем, 5 областей: задачи и данные; семейства моделей; способы обучения; компактные модели и системы; фундамент, качество и проекты. У архитектуры, обучающего сигнала и оптимизации разные роли: они могут сочетаться. Карта не претендует на перечисление всех научных публикаций.

Для всех 113 тем добавлен запускаемый Python-пример; в 25 темах есть Rust + Burn. Python 3.14 используется в инструкциях и автопроверке. Код, команды запуска, пояснения, ожидаемый результат, ограничения и задание находятся в окне чтения. Версии PyTorch 2.14.1 и Burn 0.22.1 закреплены по официальным релизам; статус численной проверки описан в `../examples/README.md`.

Основной редактируемый файл — `../map-data.json`. `map-data.js` генерируется из него при сборке. Ссылки на первоисточники включены там, где они подобраны; собственные предложения учебных проектов не выдаются за цитаты.

## Подсветка и графика

Prism 1.30.0 включён локально, без CDN. Поддерживаются Python, Rust, Bash и TOML: ключевые слова, функции, строки, числа, комментарии и остальные конструкции соответствующих грамматик. Копирование и скачивание возвращают код выбранного устройства без HTML-разметки. Короткие пояснения находятся над операциями; комментарии дополнительно переносятся по ширине окна. Лицензия MIT находится в `vendor/PRISM-LICENSE.txt`.

Поясняемые шаги разделены пустыми строками. В причинном опыте отдельно показаны сборка таблицы через `stack`, расчёт матрицы корреляций и выбор её элемента. В общих функциях обучения и проверки прогноз, ошибка и доля верных ответов вычисляются отдельными шагами. Графики и вычисления на странице находятся в `lesson-visuals.js`.

`art/topic-icons.png` — созданный для атласа лист из 24 иллюстраций. `art.js` выбирает изображение по смыслу темы. Иконки заголовков статей заданы в `ui.js`. Автономный HTML содержит всю графику и подсветку внутри файла.

## Материалы из базы

На Vercel используется Neon `ai-atlas-content` (Free, Frankfurt), подключённый только к Production. `DATABASE_URL` хранится в окружении Vercel. Платный API модели и встроенный чат не используются.

При первой production-сборке `seed-content.mjs` переносит текущие темы, Python/Burn/MLX-примеры, справочник методов и общие данные. Повторные сборки добавляют отсутствующие записи, не перезаписывая опубликованные правки. Файлы остаются резервной версией для работы без сети.

`GET /api/content?since=0` возвращает опубликованные материалы; дальнейшие запросы — только изменения. В открытом активном окне обновление проверяется каждые 30 секунд, при возвращении на вкладку и открытии материала. Через пять минут бездействия опрос приостанавливается. Обновление сохраняет вкладку, выбранное устройство, прокрутку и личные заметки. При ошибке остаётся последняя загруженная версия.

Одна запись `atlas_content` на тему: `node` — описание, `lesson` — примеры и методический материал, `layout` — оформление вкладок, `sections` — необязательная замена содержимого отдельных вкладок. `_catalog` хранит общие источники, словарь и версии библиотек. Существующая иерархия карты сохраняется.

В `layout.article`, `layout.python`, `layout.methods`, `layout.exercise` можно задавать `readerWidth`, `textWidth`, `chartsColumns` (1 или 2). Числа ограничиваются допустимыми размерами. `sections.article` и аналогичные массивы принимают блоки `text`, `list`, `code`, `chart`, `experiment`. У блока есть заголовок, ширина и выделение `info`, `task`, `warning`. `chart` содержит числовые ряды `series: [{name, values: [{x,y}]}]`, подписи `xLabel`, `yLabel` и тип `line` или `scatter`; `experiment: 'causal'` включает существующий интерактивный опыт. HTML и JavaScript из базы не исполняются.

Правки делаются после согласования в текущем разговоре через Query у этой базы в Vercel. Сначала прочитать запись и её `revision`. Затем одним запросом вызвать `atlas_publish(id, expected_revision, payload, note)`. Функция отклоняет публикацию, если кто-то успел изменить запись; триггер сохраняет каждую версию в `atlas_history`. Для возврата передать прежний `payload` в `atlas_publish` с текущим номером версии. Публичного метода записи на сайте нет. При обычных правках материалов повторный deploy не нужен.
